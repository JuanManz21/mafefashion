# Mafe Fashion

Esta es una tienda online de ropa para mujer creada con HTML, CSS, PHP y SQL.

## Configuración

1.  **Importar la base de datos:**
    *   Abre phpMyAdmin en tu servidor XAMPP.
    *   Crea una nueva base de datos llamada `mafe_fashion`.
    *   Selecciona la base de datos `mafe_fashion` y ve a la pestaña "Importar".
    *   Selecciona el archivo `mafe_fashion.sql` y haz clic en "Importar".

2.  **¡Listo!**
    *   Mueve todos los archivos del proyecto a la carpeta `htdocs` de tu servidor XAMPP.
    *   Abre tu navegador y ve a `http://localhost/`.

## Inicio de Sesión del Administrador

*   **Email:** `admin@gmail.com`
*   **Contraseña:** `12345678`

La primera vez que inicies sesión con estas credenciales, el sistema convertirá automáticamente la contraseña a un formato seguro (hash) en la base de datos. Los inicios de sesión posteriores utilizarán este formato seguro.
